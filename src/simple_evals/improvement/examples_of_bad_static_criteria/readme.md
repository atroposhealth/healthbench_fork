# Bad Static Criteria
We know there are instances in HealthBench where rubric criteria specify that a particular evidence-based answer is correct. But those answers may contradict our own evidence because the rubric is out of date, or not applicable to a particular population. We thought we had found a good example, but there turned out to be an error on our side where autosummary had reversed the direction of an effect.

This directory exists to house data, code, and infrastructure that we are using to search for more examples.
